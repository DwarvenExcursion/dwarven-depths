# Presentation

Everything is drawn with `draw_rect`. No image assets, no import step. The
palette, the dwarf and the font are all text you can edit.

## Palette

**Apollo 46** by AdamCYounis (Lospec). `scripts/apollo.gd` names every colour
and is the only place colours are allowed to come from. Highlight and shadow
pairs are always neighbours on the same Apollo ramp — that is what stops the
bevels from looking like arbitrary lightening.

The raw list is in `pallette/apollo.hex`.

## The dwarf

`scripts/dwarf.gd`. A 14x14 pixel sprite stored as two blocks of text, one
character per pixel, resolved through a key into Apollo colours:

- `IDLE` — pick over the shoulder
- `SWING` — helmet dips a pixel, pick swings down to strike

Frames face right; facing left mirrors in x, which also swaps the helmet lamp
to the leading edge. `SWING` holds for `SWING_TIME` (0.09s) after each dig,
which is what sells the digging.

Runs of identical pixels are merged and cached on first use — a naive per-pixel
draw is ~190 `draw_rect` calls per frame for one sprite; merging cuts it to
about forty.

The lamp bloom is a stepped cross, not a translucent square. A square of flat
alpha over the rock reads as a rendering bug rather than as light.

He tints toward `Apollo.DENIM` as he goes under water.

## The font

`scripts/tinyfont.gd`. A 3x5 bitmap font, uppercase only, drawn with
`draw_rect`. Godot's default font is a hinted vector face; at the 8-10px sizes
this game needs it goes soft and fights the pixel art. This stays perfectly
crisp at any integer scale.

`draw_outlined` puts a one-pixel hard shadow in all eight directions —
essential over the world, where the background can be any colour in the
palette.

Adding a glyph is adding five strings to `GLYPHS`.

## HUD

`scripts/hud.gd`. On a `CanvasLayer`, anchored full-rect, so it lands in the
real corners at any window size.

- **Top bar** — `DEPTH` with a large value, current stratum centred, `BEST`
  right. Near-opaque on purpose: at 66% the stone and dirt behind it showed
  through and the readouts sat on a blotchy, shifting ground.
- **Bottom left** — gem icon, count, then blast readiness as **pips**. You can
  read "one more gem" at a glance, which you cannot do from a bare number
  against a cost.
- **Danger** — red creeping in from the screen edges, pulsing, keyed to how
  close the wet front is. It reads peripherally, so it warns you without asking
  you to look away from the dig face.
- **Banner** — the stratum name announces itself when you cross a boundary.

## Terrain

- **Bevels** are only drawn on faces touching open space, so tunnels get
  outlined rather than the whole field turning into horizontal stripes. Since
  the rework this includes left and right faces, not just top and bottom.
- **Gems** are an inset diamond on the dirt base, so they read as ore embedded
  in rock rather than as pickups lying about.
- **Debris** — small coloured bits with gravity, spawned on dig, gem grab and
  blast.

## Screenshake

Gem grab 1.5, blast 5.0, decaying at 14/sec.

## Audio

Four synthesised chiptune WAVs at 22kHz, amplitude quantised to 8 levels,
generated by `files/make_sfx.py`. Re-run it with tweaked numbers rather than
hunting for a new tool.

| Sound | Character | Volume |
|---|---|---|
| dig | 55ms lowpassed noise + low square. Dull on purpose. | -14 dB |
| gem | Three ascending squares, 660/880/1320 Hz | -8 dB |
| blast | Noise burst over a 320->55 Hz sweep | -6 dB |
| death | 440->70 Hz descending tone with sub-octave | -6 dB |

Dig uses `pitch_scale = randf_range(0.9, 1.1)` per play. Without it, it sounds
like a machine gun.

## Controls

| Action | Keyboard | Controller |
|---|---|---|
| Move / dig | Arrows | D-Pad |
| Blast | Z | A |
| Start / restart | Enter | Start |
| Quit | Esc | Back/Select |

Everything is bound to keys **and** joypad. The key bindings are load-bearing
for the handheld: gptokeyb translates physical buttons into keyboard events, so
joypad-only bindings would do nothing on device. See [[PortMaster]].

## Settings

Master bus volume, 0.0–1.0 in 0.1 steps, persisted to `user://settings.cfg`
alongside best depth. Adjusted with left/right on the title screen — a
draggable slider was rejected because the handheld has no mouse. Plays the gem
sound on each change so you can hear what you are setting.

# Dwarven Depths — Design Doc

Endless vertical mining roguelite. Dig down, grab gems, outrun the flood.

Built in Godot 4.7.2. Target platforms: Windows desktop, Anbernic H700 handheld
(RG-xx running Stock OS Mod, via PortMaster).

---

## 1. Current State (v0.1 prototype)

### The loop

You dig straight down through procedurally generated rock. A flood rises behind
you and never stops. Gems are currency for blasts. Death is inevitable; depth is
the score.

The whole game is one script (`main.gd`) drawing colored rects via `_draw()`.
No tilesets, no sprites, no physics. Grid movement only.

### Core mechanics

| Mechanic | Detail |
|---|---|
| Movement | Grid-based. Moving into dirt destroys it and you occupy the tile. |
| Stone | Impassable. Must be routed around or blasted. |
| Gems | +1 each. Currency, not score. |
| Blast (Z / A) | Costs 3 gems. Clears a 3x3 two tiles ahead in facing direction. Recovers any gems inside the blast. |
| Flood | Rises at `0.6 + deepest * 0.01` rows/sec, but is leashed to never trail more than `FLOOD_LEAD` (6) rows behind your deepest point. |
| Death | Flood reaches your row. |
| Score | Depth reached (`deepest`), gems shown separately. |

**The leash is the key design decision.** Without it the flood was either
trivially outrun or unwinnable, because descent speed is bounded by key-repeat
rate rather than by anything interesting. Leashing it keeps the threat
permanently on screen and makes every sideways detour a real cost.

### Tuning knobs

```
MOVE_DELAY   0.11    # dig repeat rate. 0.08 frantic, 0.15 deliberate
FLOOD_LEAD   6.0     # rows the flood trails behind. 4 = panic, 8 = forgiving
BOMB_COST    3       # gems per blast
flood accel  0.01    # per-row speed ramp; sets time-to-unwinnable
```

### Strata

Four depth bands, each with its own stone/gem density and color pair. Stone
density climbing is the difficulty curve — more stone means more forced
detours, and detours cost depth directly.

| Band | Starts at | Stone | Gem | Feel |
|---|---|---|---|---|
| Surface | 0 | 0.10 | 0.07 | Tan earth, grey rock. Open, forgiving. |
| Deep earth | 60 | 0.18 | 0.06 | Dark brown, blue-grey. |
| Crystal | 130 | 0.26 | 0.05 | Purple. |
| Magma | 210 | 0.34 | 0.04 | Blood red. |

### Presentation

- **Palette:** Apollo 46 (AdamCYounis). All colors named as constants at the top
  of the script; bevel highlights are neighbors on the same Apollo ramp so
  nothing goes off-palette.
- **Resolution:** 320x240 viewport, stretch `viewport` / aspect `keep`. Doubles
  cleanly to the 640x480 panel on most H700 devices.
- **Bevels:** only drawn on faces touching open space, so tunnels get outlined
  rather than the whole field turning into horizontal stripes.
- **Gems:** inset diamond on the dirt base, reads as ore embedded in rock.
- **Flood:** solid red with a bright crest line at the leading edge.
- **Juice:** screenshake on gem grab (1.5) and blast (5.0), decaying at 14/sec.

### Audio

Four synthesized chiptune WAVs at 22kHz, amplitude quantized to 8 levels.
Generated by `make_sfx.py` — re-run with tweaked numbers rather than hunting for
a new tool.

| Sound | Character | Volume |
|---|---|---|
| dig | 55ms lowpassed noise + low square. Dull on purpose. | -14 dB |
| gem | Three ascending squares, 660/880/1320 Hz | -8 dB |
| blast | Noise burst over 320→55 Hz sweep | -6 dB |
| death | 440→70 Hz descending tone with sub-octave | -6 dB |

Dig uses `pitch_scale = randf_range(0.9, 1.1)` per play. Without this it sounds
like a machine gun.

### Controls

| Action | Keyboard | Controller |
|---|---|---|
| Move / dig | Arrows | D-Pad |
| Blast | Z | A |
| Start / restart | Enter | Start |
| Quit | Esc | Back/Select |

Everything is bound to keys *and* joypad. The key bindings are load-bearing for
the handheld: gptokeyb translates physical buttons into keyboard events, so
joypad-only bindings would do nothing on device.

### States

`TITLE → PLAY → DEAD → PLAY`. One enum in `main.gd`, no separate scenes.
`restart()` serves as both "start game" and "play again". Title screen doubles
as the settings screen (volume, left/right).

### Settings

Master bus volume, 0.0–1.0 in 0.1 steps, persisted to `user://settings.cfg` via
ConfigFile. Adjusted with left/right on the title screen — a draggable slider was
rejected because the handheld has no mouse. Plays the gem sound on each change so
you can hear what you're setting.

## 2. Open Items

### Blocking the handheld build

- [ ] **Check PortMaster's available Godot runtimes.** Runtimes are version-pinned
      (`godot_runtime="godot_4.3"` in the launch script). Built on 4.7.2. If
      there's no 4.7 runtime, the pck won't load and the project needs rebuilding
      in a supported version. **Verify this before any other porting work.**
- [ ] Get a working `.sh` — easiest path is installing any existing Godot port
      from PortMaster and copying its script, so it matches this firmware.
- [ ] Confirm on-device layout. The card uses folders and `.sh` files side by
      side in `PORTS/`, not the standard `ROMS/Ports/` + `ports/` split.
- [ ] Device needs wifi on first launch to pull the shared Godot runtime.
- [ ] Retune `MOVE_DELAY` for the d-pad. 0.11 was set on a mechanical keyboard.

### Near-term polish

- [ ] Persistent best depth (`user://best.txt`, shown on death screen). Smallest
      change that turns runs into a thing worth chasing.
- [ ] Dig particles.
- [ ] Replace `draw_rect` with a real tilesheet (Aseprite, Apollo 46).
- [ ] Separate SFX bus, so volume control doesn't dim future music.

## 3. The Mega Bonk Direction

The long-term shape: a run-based roguelite with meta-progression, in the vein of
Vampire Survivors / Mega Bonk. Everything below is unbuilt.

### Zones

Each stratum becomes a real place rather than a palette swap:

- Distinct enemy set
- Distinct hazard
- A tier boundary you either survive or don't
- Its own music track

### Enemies

Per-zone rosters. Design constraint: everything must work on a grid, with
movement resolved in discrete steps, so it stays readable at 320x240 and
playable on a d-pad.

Rough ideas:
- **Surface:** slow burrowing grubs, block your path, one hit to clear
- **Deep earth:** bats that move two tiles per turn, erratic
- **Crystal:** stationary shard emitters, hazard zones rather than chasers
- **Magma:** things that chase and are faster than you dig

### Powerups

Found or purchased mid-run:
- Faster dig (lower `MOVE_DELAY`)
- Wider blast radius
- Cheaper blasts
- Brief flood slow
- Sideways dash
- Gem magnet

### Meta-progression

- Beat a tier → unlock a cosmetic dwarf
- Customization: beard, helmet, pick, color scheme (all Apollo palette)
- Persistent unlock currency separate from in-run gems

### Structural changes required

- Enemies mean the world can no longer be a bare dict of ints — needs an entity
  layer with its own update step
- Turn-based-ish enemy movement tied to `MOVE_DELAY` ticks, not per-frame
- A run summary screen between zones
- Save file with unlock state

**Order of operations:** none of this until the core loop is confirmed fun on the
handheld. D-pad feel will change the design of every enemy in the game — an enemy
that's fair at 0.11s dig repeat may be impossible at 0.18s.

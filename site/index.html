    Installing

    1. Run the installer you downloaded above.
    2. Windows may show a blue “Windows protected your PC” screen. That is SmartScreen reacting to a new, unsigned installer — not a virus warning. Click More info, then Run anyway.
    3. Launch from the Start Menu. The game checks for updates itself from then on.

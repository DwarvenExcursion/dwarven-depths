# Patch notes for the next release

Only lines starting with `-` are picked up. Everything else here, including
this paragraph, is ignored -- so the file can explain itself without the
explanation shipping to players.

These bullets land in three places at once: the GitHub Release, the game page,
and the update panel inside the game. Keep them plain; the in-game font is
uppercase 3x5 and has no glyph for `&`.

- The dwarf falls now. A long drop is a real fall you can steer a little, and
  landing hard leaves you stunned for a moment.
- Goblins have moved into the deep caves. They block the way, go down in one
  hit, and take a gem off you if they reach you first.
- The mine runs to depth 5000 through seventeen bands of rock, each with its
  own colour, and real caverns that get bigger the deeper you go.
- Added a pause menu.
- Added music, and separate volume sliders for music and sound effects.
